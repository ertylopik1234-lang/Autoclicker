AUTO CLICKER — GITHUB BUILD

1. Create a GitHub repository.
2. Upload ALL files and folders from this ZIP.
3. Open the repository -> Actions.
4. Select "Build Auto Clicker".
5. Press "Run workflow".
6. Wait for the build to finish.
7. Open the successful run and download the artifact:
   AutoClicker-Android64
8. Inside it will be the .geode file.

The workflow builds specifically for Android64 using the official Geode build action.

The in-game button is:
AUTO: OFF -> tap -> AUTO: ON -> tap -> AUTO: OFF

CPS can be changed in Geode mod settings (1-60, default 10).
